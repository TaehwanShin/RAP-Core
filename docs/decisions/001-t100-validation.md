# 001 — T100 예외 객체로 검증 결과 통합

상태: 구현·서버 테스트 완료. 2026-09-16.

사용자가 제공한 T100 Validator와 ZCX_APP_ERROR v2를 공개 계약의 기준으로 채택했습니다.
각 위반은 필드명과 예외 객체를 보유하며, RAP 응답·BAPIRET2·예외 발생에서 같은 메시지를 사용합니다.
BO와 Handler의 의존성은 분리하되 RAP 메시지 인터페이스 타입 의존성은 허용합니다.

경고는 사용자에게 전달해야 하지만 요청 실패를 의미하지 않습니다. 따라서 메시지 유무와 오류 유무를
서로 다른 API로 표현하고 reported는 항상, failed는 오류가 있을 때만 채웁니다.

기존 in_range의 초기값 생략 의미는 유지하고 숫자 0을 검사하려는 호출자에게 명시적인 옵션을 제공합니다.
기술적 변환 오류를 검증 성공이나 빈 메시지로 숨기지 않습니다. 외부 예외 래핑은 previous를 보존합니다.

재사용 단위는 공통 클래스 2개와 메시지 클래스입니다. 최소 예제는 실행 가능한 unmanaged static action으로
따로 제공하고, root abapGit import는 `/src/`만 설치합니다. 예제의 비즈니스 저장/권한/UI 기능은 범위 밖입니다.
